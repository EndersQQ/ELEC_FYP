# Scripts

Helper scripts for setup and common operations live here.

- `setup_camera_ml_env.sh` creates `.venv` and installs camera/ML dependencies.
- `start_ui.sh` starts the browser UI bridge.
- `stop_ui.sh` stops the background UI bridge.
- `fix_serial_permissions.sh` helps with Linux serial-device permissions.

Firmware-specific upload scripts live in `../../sensors/fsr9/scripts/`.
